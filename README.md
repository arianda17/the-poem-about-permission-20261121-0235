A Python program that prints a 244-character poem about permission. The poem takes place in a kitchen: a recipe card is a permission to follow instructions exactly; when the giver crosses out her own rule and writes "ask the batter", she hands over the authority to improvise. The card ends blank where the numbers were, warm where her thumb held it — the real permission was never the recipe, but the blank space and the warmth.

## Run it

```sh
python3 main.py
```

The poem is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
